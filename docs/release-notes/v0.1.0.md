First test build of Magnetar: a Nostr NIP-35 torrent crawler and search engine, with an Android app and a server that runs in Termux on the same phone.

**Pre-release.** Everything below ran in automated tests (195 passing, plus 14 live-network tests against real relays, trackers and the DHT) and end-to-end on an Android API 37 x86_64 emulator against a live server. **It has not yet run on a real phone**, and arm64 is built but untested.

## Install on one phone

1. Install **Termux** and **Termux:Boot** from F-Droid (both from the same source). Open Termux:Boot once.
2. In Termux:
   ```sh
   pkg install -y curl
   curl -fsSLO https://github.com/awake-devel/magnetar/releases/download/v0.1.0/termux-setup.sh
   MAGNETAR_VERSION=v0.1.0 bash termux-setup.sh
   ```
   `MAGNETAR_VERSION` is required because GitHub's "latest" skips pre-releases. The script installs Postgres 18, downloads the server binary for your CPU, checks it against `SHA256SUMS`, sets up the services and prints an **API token**.
3. Android 12+: disable the phantom process killer (Android 14+: Developer options → *Disable child process restrictions*), and exempt Termux from battery optimisation.
4. Install `magnetar-v0.1.0.apk` from this release. In the app, open **Settings**: server URL `http://127.0.0.1:8787`, paste the token, tap *Test connection*.

Full guide: [README](https://github.com/awake-devel/magnetar#readme) and [docs/TERMUX.md](https://github.com/awake-devel/magnetar/blob/main/docs/TERMUX.md).

## What's in it

- Crawler for kind 2003 torrents and their comments, with per-relay cursors, relay discovery (NIP-65) and signature checks on every ingest path.
- Search: Postgres `tsvector` + `pg_trgm` on the server, SQLite FTS5 offline on the phone. Filters for category, size, date, seeders, dead swarms and trust; sorts by relevance, date, size and seeders.
- Detail view: files, trackers, infohash, publisher npub, trust explanation, liveness, comments. Open or copy the magnet, pin, hide, block a publisher.
- Liveness from UDP/HTTP tracker scrapes, with a DHT (BEP 33) fallback.
- Web-of-trust score from your root npub (follows, mutes, reports), with a light proof-of-work bonus.
- Phone cache: crawls on Wi-Fi while charging, syncs to the server over NIP-77 negentropy (batch upload as fallback), evicts only already-synced rows.
- Saved searches with local notifications (ntfy push from the server is optional).
- Downloads with librqbit on the phone (foreground service) or on the server. If the phone engine fails, the magnet opens in another torrent app.

## Known limitations

See [docs/LIMITATIONS.md](https://github.com/awake-devel/magnetar/blob/main/docs/LIMITATIONS.md). In short:
- Bridge bots (Nyaa, TPB, YGG mirrors) publish most torrents.
- Many big relays disable NIP-77.
- DHT peer counts are estimates.
- Android 15 caps phone downloads at 6 h per day.
- HTTPS trackers may fail inside the phone's download engine; UDP trackers and the DHT work.

## Files

| File | What |
|---|---|
| `magnetar-v0.1.0.apk` | Android app (arm64-v8a + x86_64), signed with a local key. A future release signed with the same key can update it in place. |
| `magnetar-server-aarch64-linux-android` | Server for Termux on a phone |
| `magnetar-server-x86_64-linux-android` | Server for Termux on x86_64 (emulators, Chromebooks) |
| `termux-setup.sh`, `termux-ctl.sh` | One-shot setup and service control (`magnetar-ctl`) |
| `SHA256SUMS` | Checksums for all of the above |

Magnetar indexes metadata that people publish on Nostr. You are responsible for what you download.
